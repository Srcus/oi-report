# 知识点清单（按 CSP-J 第二轮）

考试范围以 **CSP-J 第二轮（复赛）** 为准：4 道题，每题 100 分，满分 400。

学生档案里按这里的编号填写掌握度（0 不会 / 1 听过 / 2 会套模板 / 3 能独立写 / 4 能变形），分析脚本据此算缺口和所需课时。

|---|---|---|---|
| L1-01 | 输入输出与文件读写 | cin/cout、格式化、freopen | 6 |
| L1-02 | 变量与数据类型 | int/long long/double/char、溢出 | 6 |
| L1-03 | 运算符与表达式 | 算术、取模、比较、逻辑 | 5 |
| L1-04 | 分支 | if / else if / switch | 4 |
| L1-05 | 循环与嵌套 | for / while、break/continue | 8 |
| L1-06 | 数组 | 一维/二维、下标边界、初始化 | 8 |
| L1-07 | 字符串处理 | 遍历、比较、字符与数字互转 | 8 |
| L1-08 | 函数与作用域 | 参数、返回值、全局/局部 | 4 |

## CSP-J 第二轮四题的知识点映射
