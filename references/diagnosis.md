# 不主动思考的三种类型

同样是"不动脑"，成因不同，练法相反。类型判错，练得越多错得越远。

## 一分钟判断

拿一道他做过的题，把代码关掉，让他讲一遍思路。

- 讲不下去，或者只是把代码念一遍 → **A**
- 讲得清楚、一碰键盘就卡 → **B**
- 讲得出，但两句就带过去 → **C**

补充观察：给他一道必会的题、一道稍超一点的题，看他卡住时的第一个反应。立刻问人 / 乱试 / 放弃 = 回避；掏纸写思路、试小例子 = 在思考。

## A · 听懂了，没学会

- **是什么情况**：上课听得懂，其实是把写法记住了。问他为什么这么写，说不出来；数字一换、条件一变就写不出来。
- **怎么判断**：讲做过的题，讲到一半讲不下去；或者只会照着代码念。
- **怎么练**：退回去，两个月不学新算法。每天一道题：读题、把变量列出来、写三行思路、再动手。全程自己做，不看题解。
- **见效**：2—3 个月能看出来。

## B · 会，但不敢写

- **是什么情况**：思路有，讲得也明白，就是不敢下笔。怕写错，宁可空着，或者一直改。
- **怎么判断**：讲得清楚，但让他当场写，前面十分钟不动键盘；或者写完反复删，一直不交。
- **怎么练**：把题降到他八成都做得出来的难度。先写三行思路再碰键盘，每题都交一次，错了没关系。这阶段练的是敢写，不是写对。
- **见效**：3—4 周有明显变化，三类里最容易出成果。

## C · 觉得跟他没关系

- **是什么情况**：你讲他就听，但不会主动问，也不愿意多写一行。
- **怎么判断**：讲得出，但一两句就带过；布置任务先谈条件；一提练习就不说话，或者换话题。
- **怎么练**：别再给长线规划。让他做一个自己想要的程序，小游戏、自动签到、抓数据都行，两周做出一个能看见结果的。
- **见效**：不确定。找到他自己的目标就有转机。

## 判错会怎样

- 把 A 当 B：逼他写思路，他根本写不出来，越练越抵触。
- 把 B 当 A：反复练他早就会的东西，他觉得没意思。
- 把 C 当 B：使劲加课，人就跑了。

## 跟家长怎么说

- 还没测出来：先别定类型，说"我先观察两周"。
- 测出 B："他会，但不敢写。这一个月只做一件事：让他写出来。"
- 测出 A："他不是不聪明，是基础是听来的，得退回去补一两个月。"把"退回"说成补基础。
- 测出 C："他不觉得这事跟他有关。先给他一个自己想要的结果。"

## 无论哪种，家长只做一件事

他卡住的时候不给答案，只说一句"把你的思路写下来给我看"。这条比报多少课都管用，因为它把"动脑"从一句要求变成了一个能检查的动作。

## 止损线

如果三个月后还是连那三行都不肯写，就别再加码了：目标降为"GESP 一级 + CSP-J 第一轮证书"，精力转回文化课，特长校考仍可搏一次但不写进主计划。编程对他真实的价值是中考多一个筹码，不是必须成为选手。
